# Hearth — frontend

Next.js (App Router) frontend for the Hearth community platform.

```bash
npm install
npm run dev   # http://localhost:3000
```

Env vars: see `.env.example` (backend rewrites target `BACKEND_URL`; chat WebSocket base is `NEXT_PUBLIC_WS_URL`).

There is no public homepage — `/` is the login/signup gate; members land directly
in the forum. Signup is invite-only (codes are generated by admins in-app).
